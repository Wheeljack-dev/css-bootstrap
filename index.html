Parte 1. CSS

Lo que hay que saber de CSS puro antes de usar Bootstrap. Bootstrap no reemplaza a CSS: es CSS ya escrito, y se entiende mucho mejor sabiendo qué hace cada clase por dentro.

1.1 Qué es CSS y cómo se conecta

Definición. CSS (Cascading Style Sheets, hojas de estilo en cascada) es el lenguaje que describe la presentación de un documento HTML: colores, tipografía, tamaños, espaciados y disposición de los elementos en la pantalla.

En simple. HTML dice qué es cada cosa (un título, un párrafo, un botón); CSS dice cómo se ve. Se puede escribir en tres lugares, y el recomendado es un archivo .css aparte.

Orden de preferencia. Archivo externo, porque se reutiliza en todas las páginas y el navegador lo guarda en caché; después el bloque <style>; y el atributo style solo para algo puntual, porque no se puede reutilizar y le gana a casi todo lo demás.

1.2 Anatomía de una regla

Definición. Una regla CSS se compone de un selector y un bloque de declaraciones entre llaves. Cada declaración es un par propiedad: valor terminado en punto y coma.

En simple. El selector indica a qué elementos se les aplica; las declaraciones indican qué se les cambia.

h2.titulo {
  color: #0d6efd;
  font-size: 22px;
}
Selector
subrayado en azul: a quién se aplica
Declaración
sombreada: una instrucción completa
Propiedad
en violeta: qué se cambia
Valor
en rojo: cómo queda

Atributo, propiedad, declaración y regla. En HTML se habla de atributos: class, href, style. En CSS, de propiedades: color, border-bottom. Una propiedad con su valor forma una declaración, y un selector con sus declaraciones forma una regla. Además, border-bottom: 2px solid #dc3545 es una abreviatura de tres propiedades: grosor (border-bottom-width), estilo (border-bottom-style) y color (border-bottom-color). El estilo es obligatorio: sin solid, dashed u otro, el borde no se dibuja.

Atención. Si falta un punto y coma o una llave, el navegador descarta esa declaración (o el resto de la regla) sin mostrar ningún error. En las herramientas de desarrollador (tecla F12) las declaraciones inválidas aparecen tachadas o con un ícono de advertencia.

1.3 Cómo saber qué propiedad se puede usar en cada elemento

Definición. Cada propiedad CSS trae en su especificación dos datos que responden esa pregunta: a qué elementos se aplica (applies to) y si se hereda (inherited). Si se escribe una propiedad válida en un elemento al que no se aplica, el navegador no muestra ningún error: simplemente la ignora.

En simple. No hay propiedades “para texto” y otras “para cajas” según la etiqueta. Todo elemento HTML, sea un h2, un párrafo o un botón, se dibuja como una caja con texto adentro. Por eso border-bottom funciona en un h2: el borde no es del texto, es de la caja que contiene al texto.

Cómo comprobarlo en la práctica

  1. Documentación. Buscar “mdn” más el nombre de la propiedad (por ejemplo, mdn border-bottom). Al final de la página, la sección de definición formal (Formal definition) indica Applies to (a qué se aplica) e Inherited (si se hereda).
  2. Herramientas del navegador. F12, pestaña Elementos, panel Estilos. Una propiedad mal escrita o con un valor inválido aparece tachada con un ícono de advertencia. Una propiedad válida que no tiene efecto en ese elemento aparece atenuada, con un ícono de información que explica el motivo; por ejemplo, que width no actúa en un elemento inline.
  3. Autocompletado. En el panel Estilos, o en VS Code dentro de un archivo .css, al empezar a escribir aparecen todas las propiedades válidas y, después de los dos puntos, los valores posibles.
  4. Esta guía. El diccionario (2.4) resume esos datos para las propiedades de uso diario. En los códigos de ejemplo, cada propiedad con subrayado punteado es un enlace a su ficha.
  5. El revisor. En el probador (2.1), cada línea de CSS queda marcada como correcta, advertencia o error, con el motivo y, cuando se puede, la corrección lista para aplicar.

1.4 Selectores

Definición. Un selector es un patrón que determina a qué elementos del documento se aplica una regla.

En simple. Es la “dirección” del estilo. Los tres básicos son por etiqueta (p), por clase (.nombre) y por id (#nombre).

En la práctica. Casi todo se estiliza con clases. El id se reserva para identificar un elemento desde JavaScript o para enlaces internos (href="#seccion").

1.5 Cascada, herencia y especificidad

Definición. La cascada es el algoritmo que decide qué declaración se aplica cuando varias reglas afectan a la misma propiedad de un elemento; considera la importancia, la especificidad del selector y el orden de aparición. La herencia es la transmisión de ciertas propiedades (color, fuente) de un elemento a sus descendientes.

En simple. Si dos reglas “pelean”, gana la más específica: id antes que clase, y clase antes que etiqueta. Si empatan, gana la que está escrita más abajo. Y algunas propiedades, como el color del texto, pasan solas de padres a hijos.

Atención. !important fuerza una declaración por encima de todo. Usarlo como parche para “ganar” una pelea de especificidad vuelve la hoja de estilos difícil de mantener; conviene corregir el selector.

1.6 Colores y unidades

Definición. Los colores se expresan con nombres, notación hexadecimal (#rrggbb), rgb() o hsl(); un cuarto canal, alfa, define la opacidad. Las longitudes usan unidades absolutas (px) o relativas (%, em, rem, vw, vh), que se calculan respecto de otro valor.

En simple. Para colores, casi siempre hexadecimal. Para medidas: px cuando debe ser fijo, % para “una parte del padre” y rem para textos y espacios, porque respeta el tamaño de letra configurado por el usuario.

1.7 Texto y tipografía

Definición. Las propiedades tipográficas controlan la familia (font-family), el tamaño (font-size), el grosor (font-weight), el estilo (font-style), el interlineado (line-height), la alineación (text-align), el espaciado entre letras y la transformación de mayúsculas.

En simple. Todo lo que en un procesador de texto está en “Fuente” y “Párrafo”, en CSS son propiedades.

Atención. font-family lleva una lista: si el equipo no tiene la primera fuente, usa la siguiente. Siempre conviene terminarla con una genérica: serif, sans-serif o monospace.

1.8 Modelo de caja

Definición. Todo elemento se representa como una caja rectangular formada, de adentro hacia afuera, por el contenido, el relleno (padding), el borde (border) y el margen (margin). La propiedad box-sizing define si width y height incluyen el relleno y el borde (border-box) o solo el contenido (content-box, el valor por defecto).

En simple. El padding es el espacio de adentro, entre el texto y el borde; el margin es el espacio de afuera, entre esta caja y las demás. Con box-sizing: border-box, si se pide una caja de 260px, mide 260px y no más.

Abreviaturas. margin: 10px aplica a los cuatro lados; margin: 10px 20px es arriba y abajo, izquierda y derecha; margin: 5px 10px 15px 20px es arriba, derecha, abajo, izquierda (sentido horario). Lo mismo vale para padding. Los márgenes verticales de dos bloques seguidos no se suman: se toma el mayor.

1.9 display

Definición. La propiedad display define qué tipo de caja genera un elemento y cómo participa del flujo del documento: block, inline, inline-block, none, y los modelos de disposición flex y grid.

En simple. block ocupa toda la fila (como div, p, h1). inline va dentro del texto y no acepta ancho ni alto (como span, a, strong). inline-block va en línea pero sí acepta tamaño. none hace desaparecer el elemento.

Diferencia útil. display: none quita el elemento del todo; visibility: hidden lo vuelve invisible pero deja su hueco.

1.10 position

Definición. position establece el esquema de posicionamiento de un elemento. Junto con top, right, bottom, left y z-index, permite desplazarlo respecto de su lugar normal, de su ancestro posicionado más cercano o de la ventana.

En simple. Para poner algo en la esquina de una caja: la caja lleva position: relative y el elemento, position: absolute.

1.11 Flexbox

Definición. Flexbox (Flexible Box Layout) es un modelo de disposición unidimensional: el contenedor flexible (display: flex) distribuye a sus hijos directos, los ítems flexibles, a lo largo de un eje principal y los alinea en el eje cruzado, perpendicular al primero.

En simple. Sirve para poner cosas en fila o en columna, repartir el espacio y alinearlas. Las propiedades se escriben en el padre; los hijos se acomodan solos. Es la base de casi todo Bootstrap.

1.12 Grid

Definición. CSS Grid es un modelo de disposición bidimensional que divide el contenedor en filas y columnas, definidas con grid-template-columns y grid-template-rows; los ítems se ubican en las celdas resultantes o abarcan varias.

En simple. Flexbox ordena en una sola dirección; Grid arma una “tabla de diseño” en dos. La unidad fr reparte el espacio que sobra.

Truco. repeat(auto-fit, minmax(150px, 1fr)) crea tantas columnas como entren, cada una de al menos 150px: una rejilla que se adapta sola, sin media queries. Probar con los anchos 375 y 992.

1.13 Diseño responsive y media queries

Definición. Una media query (@media) aplica un bloque de reglas solo cuando el dispositivo cumple una condición, normalmente un ancho mínimo o máximo de ventana. El enfoque mobile first escribe primero los estilos para pantallas chicas y agrega reglas con min-width para las más grandes.

En simple. Es una condición: si la pantalla mide al menos tantos píxeles, se aplican estos estilos. Bootstrap entero está construido sobre esta idea.

Imprescindible. Sin <meta name="viewport" content="width=device-width, initial-scale=1"> en el <head>, el celular simula una pantalla de escritorio achicada y las media queries no se activan como se espera.

1.14 Variables CSS

Definición. Las propiedades personalizadas (custom properties) son variables que se declaran con el prefijo -- y se leen con var(); se heredan y pueden redefinirse en cualquier selector.

En simple. Se define un color o una medida una sola vez y se reutiliza; cambiando el valor en :root cambia todo el sitio. Bootstrap 5 expone así sus propios valores (--bs-primary, --bs-body-font-size…).

2.2 Abreviaturas: partes obligatorias y valores por defecto

Definición. Una propiedad abreviada (shorthand) asigna en una sola declaración varias propiedades individuales (longhands). Toda abreviatura define todas sus partes: las que no se escriben toman su valor inicial.

En simple. border: 10px no significa “agregar 10px de borde a lo que ya había”, sino “grosor 10px, y todo lo demás en su valor por defecto”. Como el estilo por defecto es none, el borde no se dibuja. Por eso hay que conocer qué parte es obligatoria en cada abreviatura.

2.3 Errores frecuentes

En simple. CSS nunca muestra un mensaje de error: lo que está mal, el navegador lo ignora en silencio. Estos son los errores que más se repiten. El botón Ver en el revisor abre cada uno en el probador para ver cómo se detecta y cómo se corrige.

2.4 Diccionario de propiedades

En simple. Cada propiedad con lo que hace, valores típicos, dónde funciona y si se hereda. “Se hereda: sí” quiere decir que, puesta en un elemento, también la reciben sus hijos; por eso alcanza con poner font-family en el body.

Parte 3. Bootstrap 5

Componentes y utilidades de Bootstrap 5.3. Todos los ejemplos usan la librería original, sin modificar, y se pueden copiar tal cual dentro de la plantilla del apartado 3.1.

3.1 Qué es Bootstrap y cómo se instala

Definición. Bootstrap es un framework de front-end de código abierto que provee una hoja de estilos con un sistema de rejilla responsive, clases utilitarias y componentes prediseñados, más un paquete de JavaScript para los componentes interactivos.

En simple. Es CSS ya escrito. En lugar de escribir reglas, se ponen clases en el HTML: class="btn btn-primary" y el botón ya tiene estilo. Basta con enlazar dos archivos.

Qué hace cada archivo. bootstrap.min.css trae todos los estilos. bootstrap.bundle.min.js solo hace falta para lo que se mueve: menú desplegable, modal, acordeón, pestañas, alertas que se cierran; la versión bundle ya incluye Popper, que posiciona los menús desplegables.

Sin conexión. Descargar esos dos archivos, guardarlos en la misma carpeta que esta página y cambiar dos rutas de este documento: el <link id="bs-css"> del <head> por bootstrap.min.css y el <script id="bs-js"> del final por bootstrap.bundle.min.js. Los ejemplos toman las rutas de ahí. En los proyectos propios, lo mismo: enlazar las copias locales en lugar del CDN.

3.2 Contenedor

Definición. El contenedor es el elemento envolvente de nivel superior del diseño: centra su contenido en horizontal, le aplica un relleno lateral (el gutter, 0,75rem por lado) y limita su ancho máximo según el punto de quiebre activo. Es requisito del sistema de rejilla.

En simple. Es la hoja sobre la que se arma la página: evita que el contenido quede pegado a los bordes de la pantalla y que se estire de más en un monitor grande. Hay tres variantes: de ancho fijo por escalones (.container), siempre al 100 % (.container-fluid) y mixta (.container-md y similares).

3.3 Puntos de quiebre

Definición. Los puntos de quiebre (breakpoints) son anchos de ventana a partir de los cuales cambia el diseño. Bootstrap define seis y los usa como infijo dentro de los nombres de clase: col-md-6, d-lg-none, mt-sm-3.

En simple. Una clase con infijo vale desde ese ancho hacia arriba. col-md-6 significa “media fila desde tablet en adelante”; por debajo de md manda la clase sin infijo.

Mobile first. Se diseña primero para el celular, sin infijo, y se agregan infijos para los anchos mayores: class="col-12 col-md-6 col-xl-4" se lee “fila completa en celular, media en tablet, un tercio en escritorio”.

3.4 Rejilla: filas y columnas

Definición. El sistema de rejilla es un esquema de 12 columnas basado en Flexbox: las filas (.row) son contenedores flexibles que agrupan columnas (.col-*) cuyo ancho se expresa como fracción de 12 y puede variar según el punto de quiebre.

En simple. La jerarquía es siempre contenedor, fila, columna y, recién adentro, el contenido. Cada fila tiene 12 partes: col-6 ocupa la mitad, col-4 un tercio, col-3 un cuarto. Si una fila suma más de 12, lo que sobra baja a una línea nueva.

Dos reglas que no se rompen. Las columnas tienen que ser hijas directas de .row, y el contenido va dentro de la columna, nunca directamente en la fila. El fondo de color se pone en un div interno (como .celda en el ejemplo) para no perder la separación entre columnas.

3.5 Espaciado: margin y padding

Definición. Las utilidades de espaciado son clases de una sola declaración que aplican margin o padding con una escala fija. Su sintaxis es {propiedad}{lado}-{tamaño} o, con punto de quiebre, {propiedad}{lado}-{punto}-{tamaño}.

En simple. m es margen y p es relleno. El lado: t arriba, b abajo, s izquierda (start), e derecha (end), x ambos costados, y arriba y abajo; sin letra, los cuatro lados. El número va de 0 a 5. Así, mt-3 es “margen arriba, tamaño 3”.

3.6 Display y flex utilitarios

Definición. Clases que aplican display (d-none, d-block, d-flex, d-grid…) y las propiedades de Flexbox (justify-content-*, align-items-*, flex-column, gap-*, flex-fill) directamente desde el HTML, con variantes por punto de quiebre.

En simple. Es Flexbox sin escribir CSS. Y sirve para mostrar u ocultar según la pantalla: d-none d-md-block es “oculto en celular, visible desde tablet”.

3.7 Tipografía y colores

Definición. Bootstrap normaliza los estilos base de títulos y texto y agrega clases de tamaño (display-*, fs-*, lead), grosor (fw-*), alineación (text-start, text-center, text-end) y una paleta semántica de ocho colores: primary, secondary, success, danger, warning, info, light y dark.

En simple. Los colores tienen nombre por su significado, no por el tono: success es “salió bien” (verde) y danger es “error o peligro” (rojo). text-* pinta el texto, bg-* el fondo y text-bg-* ambos, con contraste correcto.

3.8 Botones

Definición. Componente que da estilo a <button>, <a> e <input type="button"> mediante la clase base .btn y modificadores de variante (.btn-primary, .btn-outline-*), tamaño (.btn-sm, .btn-lg) y estado (disabled, .active).

En simple. Siempre van dos clases: btn más el color. Para agruparlos, btn-group; para que ocupen todo el ancho, se envuelven en un div con d-grid.

Buena práctica. <button type="button"> para acciones dentro de la página; <a class="btn"> solo cuando lleva a otra página. Dentro de un formulario, el botón que envía lleva type="submit".

3.9 Alertas y badges

Definición. La alerta es un contenedor de mensaje contextual con variantes de color semántico; con .alert-dismissible y el plugin de JavaScript puede cerrarse. El badge es una etiqueta pequeña que indica un conteo o un estado.

En simple. La alerta es el cartel de aviso después de guardar o cuando algo falla. El badge es la etiquetita con un número o una palabra corta.

3.10 Cards (tarjetas)

Definición. La card es un contenedor flexible con borde y esquinas redondeadas que agrupa contenido relacionado; admite encabezado (.card-header), cuerpo (.card-body), pie (.card-footer), imágenes y listas.

En simple. Es la ficha o tarjeta típica de los paneles. Dentro de la rejilla, cada columna lleva una card.

3.11 Navbar (menú superior)

Definición. Componente de cabecera de navegación responsive. Con .navbar-expand-{punto} se muestra expandido desde ese ancho y, por debajo, queda colapsado detrás de un botón que lo despliega mediante el plugin Collapse.

En simple. Es el menú de arriba. En este ejemplo, desde lg se ve completo; en pantallas más chicas se esconde detrás del botón de tres rayas. Probar con 375 y con 1200, y tocar el botón.

Atención. El data-bs-target del botón tiene que coincidir con el id del div.collapse (aquí, #menuPrincipal). Si no coinciden, o si falta el JavaScript de Bootstrap, el botón no abre nada y el desplegable “Reportes” no funciona.

3.12 Formularios

Definición. Bootstrap aplica estilos uniformes a los controles: .form-control (texto, correo, número, área de texto), .form-select (listas), .form-check (casillas, radios e interruptores) e .input-group (controles con prefijo o sufijo), y los organiza con la rejilla.

En simple. A cada campo se le pone form-control y a cada etiqueta form-label; el acomodo lo hace la rejilla. El for de la etiqueta debe ser igual al id del campo: así, al tocar el texto, se activa el campo.

Atención. Las clases solo dan aspecto; no validan nada. La validación se hace con atributos HTML (required, type="email", min) y, siempre, otra vez en el servidor. En esta página el envío está anulado para que el ejemplo no recargue.

3.13 Tablas

Definición. La clase base .table aplica el estilo de tabla. Modificadores: .table-striped (filas alternadas), .table-hover (resalta la fila bajo el mouse), .table-bordered, .table-sm (compacta) y variantes de color. .table-responsive, en un div envolvente, permite desplazar la tabla en horizontal en pantallas chicas.

En simple. table table-striped table-hover es la combinación típica de un listado. Siempre conviene envolverla en table-responsive para que no rompa el diseño en el celular.

3.14 List group

Definición. Componente para mostrar una serie de elementos con estilo uniforme; admite estado activo, deshabilitado, elementos accionables (enlaces o botones con .list-group-item-action) y contenido dispuesto con Flexbox.

En simple. Una lista prolija, ideal para menús laterales, avisos o resúmenes con contadores.

3.15 Collapse y acordeón

Definición. El plugin Collapse alterna la visibilidad de un elemento a partir de un disparador con data-bs-toggle="collapse" y data-bs-target. El acordeón agrupa varios bloques colapsables; con data-bs-parent, solo uno queda abierto a la vez.

En simple. Collapse es un botón que muestra u oculta un bloque. El acordeón es la lista de preguntas frecuentes donde al abrir una se cierra la otra.

3.16 Pestañas

Definición. Navegación .nav-tabs que, con el plugin Tab, muestra un solo panel .tab-pane por vez dentro de .tab-content; cada botón se enlaza con su panel mediante data-bs-target e id.

En simple. Como las pestañas del navegador o de una planilla de cálculo, pero dentro de la página.

Variante. Con nav-pills en lugar de nav-tabs, la pestaña activa se muestra como un botón con fondo de color.

3.17 Modal

Definición. Cuadro de diálogo que se superpone a la página, bloquea la interacción con el fondo y se abre con un disparador que lleva data-bs-toggle="modal" y un data-bs-target que apunta al id del .modal.

En simple. La ventanita emergente para confirmar algo. Tiene encabezado, cuerpo y pie con los botones.

Atención. El bloque .modal conviene ubicarlo al final del <body>, fuera de otros elementos con position; dentro de ellos puede quedar detrás del fondo oscuro.

3.18 Breadcrumb y paginación

Definición. El breadcrumb (miga de pan) indica la ubicación de la página actual dentro de la jerarquía de navegación. La paginación divide un listado extenso en páginas numeradas.

En simple. “Inicio / Alumnos / Ficha” arriba de la página, y los números 1, 2, 3 debajo de una tabla larga.

3.19 Ejemplo integrador: panel administrativo

Definición. Composición de los elementos anteriores en una pantalla completa: navbar, contenedor, filas con columnas responsivas, cards, tabla y list group.

En simple. Así se arma una pantalla real. Probar con 375, 768 y 1200 para ver cómo se reacomoda cada parte.
